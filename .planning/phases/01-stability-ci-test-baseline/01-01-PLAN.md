<objective>
STAB-04 — the single-highest-impact fix in Phase 1. The existing `server/main.py:639` declares `self.send_queue: asyncio.Queue = asyncio.Queue(maxsize=30)` and `enqueue()` returns False on QueueFull without requesting a keyframe. Result: a single dropped P-frame stalls the decoder for up to 2 seconds until the next natural GOP boundary. Fix: shrink to `maxsize=4`, drop the OLDEST frame on overflow (favor freshness over order), and on the **first drop of a streak** call `self.runtime.encoder.request_keyframe()` so an IDR arrives within ~100 ms. On keyframe enqueue, clear the queue (the new IDR supersedes pending P-frames) and reset the drop-streak counter.

This plan MUST land first (D-14 step 1) because every later latency / "smooth playback" claim depends on the pipeline not silently GOP-stalling.

Purpose: Every Phase 2+ latency measurement measures a corrected pipeline, not the broken one.
Output: Patched `server/main.py`, regression test with FakeEncoder fixture, canned encoded-frame data for D-02 mock boundary.
</objective>

    ```python
    async def enqueue(self, data, is_keyframe: bool = False):
        """Enqueue a frame for send. On overflow, drop OLDEST + request IDR
        on first drop of a streak. On keyframe enqueue, clear the queue so
        the new IDR supersedes any pending P-frames (STAB-04 / VIDEO-06)."""
        if is_keyframe:
            # New IDR supersedes pending P-frames
            while not self.send_queue.empty():
                try:
                    self.send_queue.get_nowait()
                except asyncio.QueueEmpty:
                    break
            self._drops_since_keyframe = 0
        try:
            self.send_queue.put_nowait(data)
            return True
        except asyncio.QueueFull:
            # Drop OLDEST (favor freshness), then enqueue the new item.
            try:
                self.send_queue.get_nowait()
            except asyncio.QueueEmpty:
                pass
            try:
                self.send_queue.put_nowait(data)
            except asyncio.QueueFull:
                pass   # Shouldn't happen after get_nowait, but be defensive
            self._drops_since_keyframe += 1
            # Request IDR on the FIRST drop of a streak only.
            if self._drops_since_keyframe == 1 and self.runtime and self.runtime.encoder:
                try:
                    self.runtime.encoder.request_keyframe()
                    logger.warning(
                        "broadcaster.idr_requested client=%s drops=%d",
                        self.client_id, self._drops_since_keyframe)
                except Exception as e:
                    logger.debug("request_keyframe failed: %s", e)
            return False
    ```
