STAB-07 — audit every async queue in the capture→encode→transport pipeline and enforce the correct drop policy. Per RESEARCH §"Pattern 4: Pipeline Bounded Queues" lines 447-457, there are 4 queues:

| Queue | Maxsize | Policy |
|-------|---------|--------|
| Capture → Encoder | 2 | Drop oldest |
| Encoder → Broadcaster | 3 | Drop oldest |
| Broadcaster → per-client send | **4** | Drop oldest + IDR-on-drop (STAB-04) |
| Input (client→server) | 64 | **Block producer** |

The broadcaster queue is already at maxsize=4 with IDR-on-drop from Plan 01. This plan covers the other three.

Single task — the module is small (~60 lines of queue wrapper logic) plus ~3 test cases. Splitting would be pure overhead.

Purpose: Prevent unbounded memory growth and latency blow-up in the pipeline. Every stage has a known-good bound + drop policy.
Output: New `server/pipelines/` package with 2 queue wrappers + tests; SessionRuntime updated to use them.

    **Create `server/pipelines/capture_queue.py`:**
    ```python
    """Capture → Encoder bounded queue (STAB-07)."""
    from __future__ import annotations

    import asyncio
    import logging
    from typing import Any, Callable, Optional

    logger = logging.getLogger("teraguchi.server.pipelines.capture")


    class CaptureQueue:
        """maxsize=2 + drop-oldest. Freshness > order for raw frames."""

        def __init__(self, maxsize: int = 2, on_drop: Optional[Callable[[], None]] = None):
            self._q: asyncio.Queue = asyncio.Queue(maxsize=maxsize)
            self._on_drop = on_drop
            self.maxsize = maxsize
            self.dropped = 0

        async def put(self, item: Any) -> bool:
            """Enqueue; on full, drop OLDEST and enqueue new. Returns True on clean
            enqueue, False if a drop occurred."""
            try:
                self._q.put_nowait(item)
                return True
            except asyncio.QueueFull:
                try:
                    self._q.get_nowait()
                except asyncio.QueueEmpty:
                    pass
                try:
                    self._q.put_nowait(item)
                except asyncio.QueueFull:
                    pass
                self.dropped += 1
                if self._on_drop:
                    try:
                        self._on_drop()
                    except Exception as e:
                        logger.debug("on_drop callback raised: %s", e)
                return False

        async def get(self) -> Any:
            return await self._q.get()

        def qsize(self) -> int:
            return self._q.qsize()

        def empty(self) -> bool:
            return self._q.empty()
    ```

    ```python
    # ── STAB-07 Capture/Encoder queue regression tests ───────────────────

    @pytest.mark.asyncio
    async def test_capture_queue_drops_oldest():
        from server.pipelines import CaptureQueue
        q = CaptureQueue(maxsize=2)
        assert await q.put(b"a") is True
        assert await q.put(b"b") is True
        assert await q.put(b"c") is False   # overflow → drop oldest (a)
        # get order: b, c (a was dropped)
        first = await q.get()
        second = await q.get()
        assert first == b"b"
        assert second == b"c"
        assert q.dropped == 1


    @pytest.mark.asyncio
    async def test_encoder_queue_drops_oldest():
        from server.pipelines import EncoderQueue
        q = EncoderQueue(maxsize=3)
        for i in range(3):
            assert await q.put(f"f{i}".encode()) is True
        assert await q.put(b"f3") is False   # overflow
        assert q.dropped == 1
        got = []
        while not q.empty():
            got.append(await q.get())
        assert got == [b"f1", b"f2", b"f3"]   # f0 dropped


    @pytest.mark.asyncio
    async def test_capture_queue_on_drop_hook():
        from server.pipelines import CaptureQueue
        drop_count = {"n": 0}
        def on_drop():
            drop_count["n"] += 1
        q = CaptureQueue(maxsize=1, on_drop=on_drop)
        await q.put(b"a")
        await q.put(b"b")   # drop a
        await q.put(b"c")   # drop b
        assert drop_count["n"] == 2


    @pytest.mark.asyncio
    async def test_input_queue_blocks_on_full():
        """Input queue (maxsize=64) must BLOCK producer, not drop."""
        import asyncio

        q: asyncio.Queue = asyncio.Queue(maxsize=2)
        await q.put("e1")
        await q.put("e2")
        # Third put should block; asyncio.wait_for with short timeout times out
        with pytest.raises(asyncio.TimeoutError):
            await asyncio.wait_for(q.put("e3"), timeout=0.05)
        # Drain one — now producer unblocks
        await q.get()
        await asyncio.wait_for(q.put("e3"), timeout=0.1)
        assert q.qsize() == 2
    ```
