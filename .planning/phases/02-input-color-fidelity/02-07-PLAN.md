QRhiTexture formats (from PySide6.QtGui):
- `QRhiTexture.Format.R16` -- 16-bit single-channel; holds 10-bit left-shifted by 6
- `QRhiTexture.Format.RG16` -- two-channel 16-bit each; holds interleaved UV

BT.709 video-range constants (verbatim from swscale):
- Y range: [16, 235] nominal in 8-bit terms; in normalized [0,1]: [16/256, 235/256] = [0.0625, 0.9180]
- UV center: 128/256 = 0.5
- BT.709 RGB matrix coefficients: R = Y + 1.5748*V ; G = Y - 0.1873*U - 0.4681*V ; B = Y + 1.8556*U
- Video-range scale for Y: multiply by 1.1643 (255/219)
- Video-range scale for UV: 1.1384 (255/224)

```
#version 440
// Teraguchi Phase 2 D-02: BT.709 video-range YUV(10-bit) -> RGB fragment shader.
// Source: ITU-R BT.709 / BT.1361; cross-verified against FFmpeg swscale BT.709.
// Input:
//   yTex  : QRhiTexture.R16  holding Y  plane (10-bit left-shifted into 16-bit container).
//   uvTex : QRhiTexture.RG16 holding UV plane (interleaved, half-res, 10-bit-in-16).
// P010 sampler note: Qt R16/RG16 normalize to [0,1] over 16-bit range.
// For video-range BT.709: Y in [16/256, 235/256], UV center 128/256=0.5.

layout(binding = 1) uniform sampler2D yTex;
layout(binding = 2) uniform sampler2D uvTex;
layout(location = 0) in vec2 v_uv;
layout(location = 0) out vec4 fragColor;

void main() {
    // BT.709 video-range. Y scale = 255/219 ~= 1.1643; UV scale = 255/224 ~= 1.1384.
    float Y  = (texture(yTex,  v_uv).r  - 0.0625) * 1.1643;
    vec2  UV = (texture(uvTex, v_uv).rg - vec2(0.5, 0.5)) * 1.1384;
    float R = Y + 1.5748 * UV.y;
    float G = Y - 0.1873 * UV.x - 0.4681 * UV.y;
    float B = Y + 1.8556 * UV.x;
    fragColor = vec4(R, G, B, 1.0);
}
```

```python
import ctypes
import CoreVideo as CV
# Lock both planes for write
CV.CVPixelBufferLockBaseAddress(pixel_buffer, CV.kCVPixelBufferLock_ReadOnly)
try:
    y_base = CV.CVPixelBufferGetBaseAddressOfPlane(pixel_buffer, 0)
    y_stride = CV.CVPixelBufferGetBytesPerRowOfPlane(pixel_buffer, 0)
    uv_base = CV.CVPixelBufferGetBaseAddressOfPlane(pixel_buffer, 1)
    uv_stride = CV.CVPixelBufferGetBytesPerRowOfPlane(pixel_buffer, 1)
    # Y plane: height rows, 2 bytes per pixel (R16)
    for row in range(height):
        ctypes.memmove(
            y_base + row * y_stride,
            ctypes.c_char_p(y_bytes[row * width * 2 : (row + 1) * width * 2]),
            width * 2,
        )
    # UV plane: height/2 rows, 4 bytes per pair of pixels (RG16)
    for row in range(height // 2):
        ctypes.memmove(
            uv_base + row * uv_stride,
            ctypes.c_char_p(uv_bytes[row * width * 2 : (row + 1) * width * 2]),
            width * 2,
        )
finally:
    CV.CVPixelBufferUnlockBaseAddress(pixel_buffer, CV.kCVPixelBufferLock_ReadOnly)
```
